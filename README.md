# opencode-webdev — archived

This repository has moved. The skills and coding rules now live in one
tool-independent collection that covers opencode alongside every other agent:

**https://github.com/alpham8/agentic-webdev**

The opencode configuration lives there under `adapters/opencode/` — `AGENTS.md`,
`opencode.json` and `plugins/hooks.ts`, unchanged. `install.sh` detects opencode
and installs the rules and skills for it.

Keeping the collection in two repositories meant maintaining the same `skills/`
and `rules/` twice, and they drifted apart without anyone noticing. The merged
repository holds them once.
